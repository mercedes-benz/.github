# Mercedes-Benz Group Open Source Project Conventions

## Project Naming Convention

- Avoid Overly Long Project Names
- Use Dashes `-` to Separate Words in Project Names, e.g. `mosim-backend`
- Use Lowercase Letters for Project Names, e.g. `mosim`
- Alternatively Use Uppercase Letters for Codenames, e.g. `MOSIM`
- Avoid Camel Case or Snake Case, e.g. Do Not Use `Mosim` or `mosimBackend`
- For Multi-Repo Projects: Prefix the Project with a Fixed Project Group Name Followed by Underscore `_`, e.g. `MOSIM_core` and `MOSIM_backend`

## Projects with Multiple Repositories

- Use Either a Mono-Repo or Multiple Repos with a Clearly Defined Prefixed Project Name Followed by an Underscore: `<Project-Prefix>_<Component>-<More-Words>`
